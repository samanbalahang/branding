# Branding - WordPress Business Theme

A modern and customizable WordPress branding and business theme built with **WordPress 7.x**, **Advanced Custom Fields (ACF)**, and the **Astra Theme Framework**.

## 🌐 Live Demo

**Demo Website:**
https://samanbalahang.github.io/branding

## ✨ Features

* Modern branding-focused design
* Fully responsive layout
* Built on top of Astra Theme
* Advanced Custom Fields (ACF) integration
* SEO-friendly structure
* Fast loading and optimized assets
* Custom homepage sections
* Reusable template parts
* Clean and maintainable codebase
* Easy customization through WordPress Admin

## 🛠 Requirements

* WordPress 7.x
* PHP 8.1+
* Astra Theme
* Advanced Custom Fields (ACF) Plugin

## 📦 Installation

### 1. Install WordPress

Create a fresh WordPress installation.

### 2. Install Astra Theme

Download and activate Astra:

https://wordpress.org/themes/astra/

### 3. Install ACF Plugin

Download and activate Advanced Custom Fields:

https://wordpress.org/plugins/advanced-custom-fields/

### 4. Install This Theme

Clone the repository or download the ZIP file.

```bash
git clone https://github.com/samanbalahang/branding.git
```

Copy the theme folder into:

```text
wp-content/themes/
```

Activate the theme from:

```text
WordPress Dashboard → Appearance → Themes
```

### 5. Import ACF Fields

Import the included ACF field groups if provided with the project.

## 📦 نصب قالب

### ۱. نصب وردپرس

ابتدا یک نسخه جدید از وردپرس را نصب کنید.

### ۲. نصب قالب Astra

قالب Astra را دانلود و فعال کنید:

https://wordpress.org/themes/astra/

### ۳. نصب افزونه ACF

افزونه Advanced Custom Fields را نصب و فعال نمایید:

https://wordpress.org/plugins/advanced-custom-fields/

### ۴. نصب قالب

مخزن را کلون کرده یا فایل ZIP را دانلود کنید:

```bash
git clone https://github.com/samanbalahang/branding.git
```

سپس پوشه قالب را در مسیر زیر قرار دهید:

```text
wp-content/themes/
```

و از بخش زیر آن را فعال کنید:

```text
پیشخوان وردپرس ← نمایش ← پوسته‌ها
```

### ۵. درون‌ریزی فیلدهای ACF

در صورتی که فایل خروجی فیلدهای ACF در پروژه قرار داده شده است، آن را در افزونه ACF درون‌ریزی نمایید.
